What changed

The latest observation (November 26, 2026) is 4.7°F, up 0.2°F from 4.5°F (November 25, 2026). The anomaly is a trailing 30-day window, so this compares consecutive daily vintages rather than two calendar months.

Why it matters

A 30-day anomaly tells you whether the season is running warm or cool, not whether tomorrow will rain. Each station is measured against its own 1991-2020 normals, so the number is a local baseline, not a statewide average.
