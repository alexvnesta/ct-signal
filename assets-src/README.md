# Art sources

The shipping brand art (masthead band, social covers, digest header, story
covers) is built from `hartford-skyline-dark.png`, rendered from
`hartford-skyline-brand.svg`, generated by `scripts/hartford_skyline.py`
— our own drawing script: every building is a shapely polygon, windows are
boolean-subtracted so they are real transparent holes, and the front
landmarks are knocked out of the back layer (clean vector, print-ready).
Ours: no license, no attribution, no stock-site watermark.

What it depicts, left to right: the Soldiers and Sailors Memorial Arch and
the stone-arch bridge at Bushnell Park, the State Capitol with its gilded
dome (painted as its own layer — it really is gold), City Place, the
Travelers and 777 Main towers, the Bushnell complex. Composed view, not a
survey. The earlier claim that tower heights matched Wikipedia's list was
true of a since-deleted prototype, not of this art; the drawing is
stylized and says so.

To regenerate after editing the script: run it with the `--brand` flag
(needs shapely; any plain python3 works), then rasterize transparent at
2× (`npx @resvg/resvg-js` or resvg CLI), crop, and save over
`hartford-skyline-dark.png`. The build itself only composites the PNG —
CI never needs shapely or a rasterizer.

Retired sources, kept for the record, no longer rendered into any shipping
asset: `hero-waveform.webp`, `hero-skyline.webp`, `hero-contours.webp` —
Stable Horde / SDXL anonymous-worker generations from the first brand kit.

`scripts/ct_poly.json`: Connecticut outline extracted from Natural Earth 10m
admin-1 boundaries (public domain, ne_10m_admin_1_states_provinces).
